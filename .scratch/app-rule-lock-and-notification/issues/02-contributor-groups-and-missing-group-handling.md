# 02: 기여 앱 그룹별 조건 및 삭제된 그룹 엔드투엔드 처리

**What to build:** 앱 규칙에 여러 기여 앱 그룹(예: 학습 앱, 독서 앱 등) 조건이 걸려 있을 때 각각의 채운 시간과 부족 시간이 개별 항목으로 잠금 화면과 알림에 표시된다. 기여 앱 그룹이 삭제되었을 때는 오류나 내부 ID 노출 없이 "알 수 없는 앱 그룹 (규칙 설정 확인 필요)"으로 안전하게 표시된다.

**Blocked by:** 01: 전체 사용 조건 미달 시 잠금 화면 및 알림 엔드투엔드 표시

**Status:** done

- [x] 전체 조건 외에 개별 기여 앱 그룹 조건들의 진행 시간과 부족 시간이 합산되지 않고 각각 잠금 화면에 독립 글머리 기호(•) 항목으로 나열된다.
- [x] 잠금 화면에서 각 기여 그룹 조건의 부족 시간도 1분 미만 시 1분 올림 규칙이 동일하게 적용된다.
- [x] 알림에서 여러 미충족 조건이 쉼표로 나열되어 표시된다 (예: `전체 (8m/20m), 학습 (5m/15m)`).
- [x] 삭제되거나 찾을 수 없는 기여 앱 그룹은 내부 ID나 예외 대신 "알 수 없는 앱 그룹 (규칙 설정 확인 필요)" 문구로 표시되어 사용자가 원인을 확인할 수 있다.
- [x] 복수 기여 앱 그룹 진행 및 삭제된 그룹 시나리오에 대한 단위 테스트가 작성되고 통과한다.
