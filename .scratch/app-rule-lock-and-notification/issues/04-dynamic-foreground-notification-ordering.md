# 04: 실시간 전면 앱 전환 및 4단계 알림 정렬

**What to build:** 사용자가 앱을 전환하거나 홈으로 나갈 때 상단바 알림의 제목과 접힌 알림 내용이 현재 전면 앱의 규칙으로 즉각 갱신되며, 펼쳤을 때 (1) 전면 앱 차단 규칙 (2) 전면 앱 허용 규칙 (3) 전면 앱 외 잠긴 규칙 (4) 기타 활성 규칙의 4단계 우선순위로 실시간 재정렬된다. 활성 시간 구간(스케줄) 밖의 규칙은 알림에서 제외된다.

**Blocked by:** 01: 전체 사용 조건 미달 시 잠금 화면 및 알림 엔드투엔드 표시, 02: 기여 앱 그룹별 조건 및 삭제된 그룹 엔드투엔드 처리, 03: 사용 가능 시간 소진 및 복합 상태 우선순위 판정

**Status:** done

- [x] 현재 시간 구간(스케줄 윈도우)에 속하지 않는 규칙은 알림 목록에서 제외된다.
- [x] 전면 앱 변경 이벤트(`TYPE_WINDOW_STATE_CHANGED`) 발생 시 알림 모델이 실시간으로 재계산되고 갱신된다 (중복 I/O 방지).
- [x] 알림 제목이 `Curbox • [현재 전면 앱 규칙명]`(전면 규칙이 없으면 1순위 규칙명)으로 표시된다.
- [x] 펼친 알림에서 활성 규칙들이 (1) 전면 차단 (2) 전면 허용 (3) 타 앱 차단 (4) 타 앱 허용의 4단계 우선순위로 정렬되며, 동일 범주 내에서는 기존 스냅샷 설정 순서를 보존한다.
- [x] 접힌 알림에는 4단계 우선순위 1위 규칙의 상태가 표시된다.
- [x] 포그라운드 알림의 잠금 화면 공개 수준을 `NotificationCompat.VISIBILITY_PUBLIC`으로 설정한다.
- [x] 전면 앱 전환에 따른 동적 정렬 및 필터링 시나리오에 대한 단위 테스트가 작성되고 통과한다.
