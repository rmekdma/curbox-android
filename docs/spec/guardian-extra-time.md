# 잠금 화면 보호자 추가시간 총량 입력 사양서 (Guardian Extra Time Total Specification)

> **문서 목적 및 위치**  
> 본 문서는 앱 규칙 잠금 화면에서 보호자가 추가시간을 증분(Delta) 또는 목표 총량(Target Total)으로 양방향 입력하고 관리하는 기능의 UI/UX 상호작용 및 비즈니스 사양서입니다.

---

## 1. 배경 및 문제 정의 (Problem Statement)

앱 규칙 잠금 화면에서 보호자는 기존에 단순히 "새로 지급할 시간(분)"만 입력할 수 있었습니다.
이미 해당 규칙에 지급된 보호자 추가시간이 있더라도 현재 총량을 보면서 목표치(예: "오늘 총 40분이 되도록 맞추기")를 직접 설정할 수 없어, 이전 지급량을 기억하고 차이를 암산해야 하는 불편함이 있었습니다.

보호자는 다음 두 가지 입력 방식을 동일한 결과로 편리하게 사용하고자 합니다:
1. `현재에 10분을 더 지급한다` (증분 입력: Delta)
2. `오늘 총 지급량이 40분이 되도록 한다` (목표 총량 입력: Target Total)

---

## 2. 해결 방안 (Solution)

잠금 화면의 `추가 시간` 동작을 **`추가 시간 변경`**으로 변경하고, 선택된 앱 규칙의 현재 사용일에 지급된 보호자 추가시간 총량을 표시하며 두 개의 양방향 연동 입력을 제공합니다:

- **`추가 시간`**: 현재 총량에 새로 더할 분 (Delta)
- **`총 추가 시간`**: 적용 후 도달할 최종 총량 (Target Total)

```
       [현재 총 추가 시간 N분]
                  │
 ┌────────────────┴────────────────┐
 │                                 │
 ▼                                 ▼
[추가 시간] ◀── 양방향 연동 ──▶ [총 추가 시간]
(현재 + delta)               (target - 현재)
```

두 입력 필드는 실시간으로 연동되어 한쪽을 수정하면 다른 쪽이 즉시 재계산됩니다.
잠금 화면에서는 **총량의 증가만 허용**되며, 저장 시에는 기존 지급 원장을 보존하고 **현재 총량과 목표 총량의 차이(양수 차이)만 새 레저 항목으로 추가**합니다.

---

## 3. 핵심 비즈니스 및 도메인 규칙

### 3.1 양방향 계산 규칙
1. **현재 총량 기준**: 선택된 규칙의 정규화된 현재 사용일(use day) 지급 총량을 $T_{\text{current}}$라고 합니다.
2. **추가 시간($\Delta$) 입력 시**:
   $$\text{총 추가 시간} = T_{\text{current}} + \Delta \quad (\Delta > 0)$$
3. **총 추가 시간($T_{\text{target}}$) 입력 시**:
   $$\text{추가 시간} = T_{\text{target}} - T_{\text{current}} \quad (T_{\text{target}} > T_{\text{current}})$$
4. **유효하지 않은 입력 처리**:
   - $T_{\text{target}} \le T_{\text{current}}$ 이거나 파싱 불가능한 입력 중에는 유도되는 `추가 시간` 필드를 빈 칸으로 유지하며, 음수 값을 표시하지 않습니다.
   - 양수 값 앞에 `+` 기호를 붙이지 않습니다.

### 3.2 격리 및 누적 불변식
- **규칙 및 사용일 단위 완전 격리**: 다른 규칙의 추가시간이나 과거 사용일(만료된 이전 날짜), 다른 세대(use day generation)의 지급 기록은 현재 총량에 포함되지 않습니다.
- **불변 원장(Append-only Ledger)**: 기존에 지급된 레저 항목을 수정하거나 덮어쓰지 않고, 차이분만 새로 추가하여 영속화합니다.
- **다중 거부 처리**: 하나의 잠금 화면에서 규칙 A를 승인하더라도, 여전히 거부 중인 다른 규칙 B가 남아있다면 잠금 상태를 유지합니다.

## 4. UI/UX 및 입력 인터랙션 상세

1. **라벨 및 타이틀**:
   - 액션 및 팝업 타이틀: `추가 시간 변경`
   - 상단 안내: `현재 총 추가 시간 N분`
   - 입력 필드 라벨: `추가 시간`, `총 추가 시간`
2. **플레이스홀더 및 포커스 동작**:
   - `총 추가 시간` 필드는 초기 상태에서 빈 칸이며, 플레이스홀더로 현재 총량($T_{\text{current}}$)을 표시합니다.
   - 첫 터치 시 빈 편집 필드가 제공되어 기존 값을 지우지 않고 바로 목표 숫자를 입력할 수 있습니다.
   - 자동 계산된 값 또는 이미 입력된 필드를 터치하면 전체 텍스트가 선택(Select All)되어 한 번에 덮어쓸 수 있습니다.
3. **검증 및 에러 처리**:
   - 입력 도중에는 에러를 띄우지 않고, `적용` 버튼을 눌렀을 때 검증합니다.
   - `적용` 버튼은 비활성화하지 않고 항상 탭 가능 상태를 유지합니다.
   - **에러 조건**:
     - 같거나 작은 목표치 제출 시: `"총 추가 시간은 현재 값보다 커야 해요."`
     - 공백, 0, 숫자가 아닌 입력, 정수 오버플로 시: 입력 필드 에러 표시 및 다이얼로그 유지.
4. **인증 및 완료 흐름**:
   - 폼 입력 검증 통과 후에만 보호자 비밀번호 인증을 시작합니다.
   - 인증 취소 또는 실패 시 변경 사항을 기록하지 않고 종료합니다.
   - 인증 성공 및 데이터 저장 완료 후에만 잠금 화면을 닫고 대상 앱을 재실행(Relaunch)합니다.

---

## 5. 범위 제외 사항 (Out of Scope)

- 지급된 보호자 추가시간 총량을 감소시키거나 취소하는 동작.
- 음수 분 입력.
- 앱 규칙 설정 관리 화면에서의 추가시간 총량 편집.
- 여러 규칙이 공유하는 전역 추가시간 풀(Global Extra Time Pool) 도입.
- Room 스키마 변경, 설정 JSON 구조 변경 또는 마이그레이션.
