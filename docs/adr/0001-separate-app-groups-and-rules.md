# 앱 그룹과 앱 규칙 분리

기존 `AppGroup`은 앱 목록, 일정과 사용량 제한을 한 객체에 묶지만, 새 요구사항은 같은 앱 묶음을 적용 범위와 기여 계산에서 재사용하고 한 규칙에서 포함과 제외를 조합해야 한다. 앱 그룹을 이름과 앱 목록만 가진 중립 객체로 만들고, 앱 규칙이 요일, 시간 구간, 적용 범위, 사용 가능 시간과 기여 정책을 소유하도록 분리한다. 그룹과 규칙은 이름 변경에도 유지되는 불변 ID를 사용하고 하나의 원자적 제한 스냅샷으로 검증, 지연 및 적용한다. 이 결정은 기존 설정 모델과 UI를 마이그레이션해야 한다는 비용이 있지만, 그룹 활성 상태가 추적과 제한을 동시에 바꾸는 모호함과 부분 적용된 깨진 참조를 없앤다. 규칙의 적용 범위는 포함 합집합에서 제외 합집합을 빼며, 대상 그룹은 참조 중 단순 삭제를 거부하고 기여 그룹이 사라지면 알려진 대상 범위를 허용하지 않는다. 손상된 새 스냅샷은 마지막 유효 스냅샷을 교체하지 않는다.
