# Device Owner를 사용하지 않는 보호

Device Owner와 Lock Task는 가장 강한 기기 잠금을 제공하지만 등록과 해제 실패 시 공장 초기화가 마지막 복구 수단이 될 수 있고, 개인용 태블릿에 대한 사용자의 복구 위험 허용 범위를 넘는다. Curbox는 Device Owner를 사용하지 않고 접근성 서비스, 오버레이와 일반 Device Admin을 이용해 설정 접근과 제거를 어렵게 만드는 최선형 보호를 제공한다. 이 선택은 Lock Me Out과 유사한 배포 편의성과 일반 삭제 복구를 유지하지만, 안전 모드, 강제 중지, OEM 시스템 화면과 물리적 복구 경로를 키오스크 수준으로 차단한다고 약속할 수 없다는 한계를 UI와 문서에 명시한다.
