# 현재 사용일 전면 세션 저장

기존 Room 데이터는 앱별 날짜와 시간대 합계만 저장하므로 임의 시각의 규칙 구간, 건너뛴 구간, 분할 화면과 앱 그룹의 `오늘부터 적용`을 정확히 재계산할 수 없다. 앱별 집계는 유지하면서 현재 사용일에 필요한 짧은 전면 세션과 실행 이벤트 원장을 Room에 추가하고, 현재 사용일 시간의 권위 데이터와 규칙 사용량은 이 원장에서 계산한다. 기존 날짜 및 시간대 집계는 과거 표시, 동기화와 빠른 조회를 위한 파생 데이터로 유지한다. 사용량 초기화는 현재 사용일 원장에서 제거할 차이를 계산해 하나의 Room 트랜잭션에서 세션을 절단하고 기존 집계에서 정확한 차이만 차감하므로 같은 달력 날짜의 이전 사용일 데이터를 보존한다. 통계 추적이 꺼져도 활성 규칙 판정에 필요한 원장은 임시 기록하지만 과거 통계나 동기화에는 합치지 않는다. 상세 데이터가 늘고 데이터베이스 버전 변경이 필요하지만 여러 규칙별 카운터를 따로 동기화하는 것보다 원시 사실을 한 번 저장하고 파생 값을 계산하는 편이 일관적이다. 현재 데이터가 없다는 전제에서 사용자는 파괴적 마이그레이션을 승인했으며, 상세 원장은 현재 사용일 계산에 더 이상 필요하지 않으면 정리한다.
