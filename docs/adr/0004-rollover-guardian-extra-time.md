# 미소진 보호자 추가시간 이월 및 주기별 누적

기존 보호자 추가시간은 당일 사용일(복원 시각 기준)에만 유효하고 다음 복원 시각에 전량 소멸하므로, 평일에 늦게 시작해 야간 취침 잠금 등으로 다 쓰지 못한 추가시간을 주말 등 특정 날에 활용할 수 없다. 앱 규칙에 이월 기능과 해금 요일 다중 선택을 추가하여 요일을 적립일과 해금일로 분리한다. 적립일에 다 쓰지 못한 보호자 추가시간은 사용일 복원 시각(오전 4시)에 누적 보관함으로 이월된다. 해금일에는 기본 사용 가능 시간이 소진되면 앱이 잠기며, 보호자는 잠금 화면에서 당일 추가시간을 지급하거나 누적 시간 승인 팝업(전량 placeholder 제공, 빈 값 제출 시 전량 승인)을 통해 누적 시간을 꺼내 쓸 수 있다. 토요일에 지급했으나 소진하지 못한 당일 추가시간과 잔여 누적 시간은 연속된 다음 해금일(일요일)의 누적 풀로 함께 합산되어 이월된다. 누적 시간은 연속된 해금일 구간이 종료되고 다음 적립일이 시작되는 복원 시각에 전량 소멸(구간별 리셋)하여 시간이 무제한 누적되는 것을 방지한다. 취침 잠금 등 시간 구간 제한은 잔여량과 무관하게 엄격 차단되며, 기본 사용 가능 시간의 미소진분은 이월하지 않고 오직 보호자 추가시간만 이월한다. 이미 관리 잠금을 통과한 Curbox 앱 내에서는 중복 인증 없이 누적 시간을 직접 확인하고 변경할 수 있다.
